Mecanum Wheel Autonomous Robot

Designed and built a holonomic-drive robot using mecanum wheels to achieve full 360° movement for advanced mobility and control testing in robotics systems.

Overview

This project focuses on the design and implementation of a mecanum wheel drive system capable of omnidirectional movement. The robot was developed as part of hands-on robotics experimentation with motion control, kinematics, and embedded systems.

My Role

  • Designed chassis layout and wheel placement in CAD
  • Implemented mecanum drive kinematics logic
  • Programmed Arduino-based motor control system
  • Tested movement algorithms for strafing and rotation
  • Debugged motor synchronization issues

Tools & Technologies

SolidWorks Arduino C++ DC Motors Mecanum Wheels Control Systems 3D Printing MATLAB

Engineering Challenges

  • Correcting drift caused by uneven wheel friction
  • Balancing torque across all four motors
  • Implementing accurate strafing movement
  • Tuning control signals for smooth motion

Design Process

The design began with CAD modeling of the chassis and wheel configuration. Multiple iterations were required to optimize weight distribution and wheel alignment. Control logic was developed and refined through repeated testing of movement vectors.
